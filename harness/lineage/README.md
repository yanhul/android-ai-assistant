# Durable Research Lineage

The autonomous coding loop persists solution ancestry outside model context.

## Lifecycle

`OBSERVE -> LOAD LINEAGE -> HYPOTHESIZE -> IMPLEMENT -> TEST -> CI -> VERIFY -> PERSIST -> PROMOTE/REJECT -> NEXT ITERATION`

Each iteration records parent artifacts, exact change, commit, test/CI evidence, findings, constraints and unresolved claims. Failed attempts remain queryable so later iterations do not blindly repeat them.

## Hard boundary

The agent may not modify governing policy, harness control contract, acceptance criteria, evidence requirements, iteration budget, security controls or terminal conditions. These remain outside agent authority as required by `AGENT_POLICY.md`.
